# 03 — Case-Study Analysis

The [case-study index](https://www.cynbit.in/case-studies) links to 13 details and shows four filter controls. On 23 November 2026 IST, two interaction methods in headless Brave, including a pointer run with hit targets verified, left all 13 card links listed after each category selection. On the pointer run the count was checked 600 ms after each click. The expected category counts from the displayed labels were Cloud Strategy 2, Digital Marketing 2, and Software Development 9. This is reproducible in the test environment. Other browser and normal-profile behavior is Not Tested.

All four hero images rendered. Each page has Challenge, Solution, and Outcome sections. Each repeats the general 99.9% performance and 24/7 reliability badges. The visible article bodies contained no original product screenshot, live demo, external client link, interactive product component, attributed client reference, or source explaining how an outcome was measured. These are first-party claims with named projects. Independent verification and the other nine details are Not Tested.

Visitors can already read project narratives, so the proposed explorer should make projects easier to find and supply better evidence where the content owner can approve it. Treat category filtering as a primary acceptance check and distinguish published claims, approved source material, and prototype examples in the UI.
